# v0.1.4-beta.5 发布检视

日期：2026-10-01。基线：v0.1.4-beta.4（daf589d）。覆盖本版本播放页布局、详情菜单、搜索范围、对应测试及分发文件，逐项核对 ARCHITECTURE.md、TEST_RELEASE.md、RELEASE.md 和本轮用户需求。

## 规范与实现

未发现阻止发布的问题。

- 播放页继续复用 PlaybackService 和现有 ViewModel 操作，未创建第二个播放器；切换风格、打开详情及导航不修改播放进度。
- 歌单写入仍由已有网关负责。详情菜单离线禁用加入歌单和收藏，保留本机定时、音效、风格及音频信息；缺少歌手或专辑元信息时禁用对应导航。
- 详情内容提取为独立组件，滚动高度有界；快捷操作和行操作保留可访问按钮语义。跳转歌单或歌手专辑前关闭详情，避免重叠菜单。
- 搜索范围由导航参数传入，歌单 ID 经 URI 编码，底部导航与页面转场识别新路由；不依赖 ViewModel 中上次选中的歌单。
- 在后台线程按范围建立索引，再执行关键词、下载和智能筛选。作用范围变更时重建索引和结果状态；已删除或未知歌单不会回退全局。歌曲去重继续使用服务器联合身份。
- 不新增依赖，不修改数据库结构，不轮换上传密钥。运行时依赖许可清单重新生成，仍为 113 项，源码分发保留完整许可与 NOTICE。

## 需求核对

没有未完成的本轮要求。

- 播放页按参考图精简常驻操作：收藏在歌名旁，下载、评论、「更多」共用一排；定时停止、加入歌单、样式、歌手专辑、音效、音频信息及歌词设置进入详情菜单。活跃定时器仍可在主界面直接调整。
- 保留经典、沉浸和三种音波，以及双语、罗马音、逐字和偏移功能；封面和歌词视图均能进入更多操作。
- 音乐库总览及智能曲库入口为全局搜索，歌单内入口只搜索该歌单；范围提示、拼音、历史查询、下载筛选、智能筛选和听歌统计遵守相同范围。
- 点击其他歌曲时传入当前范围结果队列；点击已经播放的歌曲继续打开播放页并保留队列和进度，沿用原有行为。返回搜索入口仍可浏览原歌单。
- 检视中修正使用说明里过时的专辑入口和结果播放描述，并校正旧测试记录中可选录屏跳过的计数；未将跳过计为通过。
