# v0.1.3 · 自动同步与播放缓存

相对已发布的 **v0.1.2**，本版本更新音乐库同步、最近播放与离线缓存体验。

- **音乐库自动同步**：接收 Any Listen Web Server 的歌单变化通知，合并连续变化，只回读受影响或新增歌单。移除音乐库和歌单详情的手动刷新按钮、进度条。
- **漏通知补偿**：推送初始化失败自动重连；回到前台时按至少 1 分钟的间隔补查，在线约每 5 分钟完整校对。未发生内容变化时不重复写入音乐库，也不强制刷新音频、封面或歌词缓存。
- **最近播放**：对齐服务端 `last_played` 清单，记录播放歌曲并按最近播放顺序展示；从最近播放清单播放时保持其顺序。
- **播放缓存**：按文件偏移合并播放、跳转与重试读取的音频数据，完整后可在本地页离线使用。修复有限长度读取、提前 EOF 或半成品丢失时可能误判完整缓存的问题。
- **加载状态**：缓冲时播放按钮显示加载指示，避免与暂停状态混淆。
- **默认封面**：使用配套的青绿色清单与靛蓝色歌曲矢量封面，替换无封面时的文字占位。

## 安装与兼容性

Android 8.0 及以上；当前适配 [Any Listen Web Server](https://github.com/any-listen/any-listen-web-server) v0.11.0-beta.1，需要手机可访问的 HTTPS 服务地址。本项目不提供音乐资源或公共服务器。

版本号 **0.1.3**，versionCode **10**。正式包名仍为 `io.github.nutea.anylisten`，沿用 v0.1.2 的 CI 上传密钥，可覆盖安装 v0.1.2；与 `.debug` 调试版独立。旧 v0.1.0 签名不同，不能直接覆盖安装。
