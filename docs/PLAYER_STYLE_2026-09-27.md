# 播放页背景风格

新增「沉浸封面」，参考用户提供的大封面渐隐示例。默认保持「经典」，入口位于播放页封面标签右上角调色盘。

- 全幅封面向顶部暗色和底部主色渐隐；优先从封面底部提取有彩色像素，以衔接图像边缘。
- 取色使用后台线程与最长边不超过 64 像素的采样图，按封面内容缓存键更新，播放进度更新不会重复解码。
- 沉浸模式使用浅色控件、深色底和歌词遮罩；系统栏使用浅色图标，离开后恢复应用主题。
- 选择通过 DataStore 持久保存，不改变队列、歌词设置或播放进度。无封面和加载失败使用深色渐变与音符占位。
- 复用已有封面缓存，离线时也可显示已缓存封面。用户参考图片仅用于本地截图验证，未纳入应用资源。

验证：Debug APK / AndroidTest APK 构建及 Debug Lint 通过；标准尺寸下 7 项设备回归通过，覆盖风格切换、偏好持久化、无封面、经典播放模式与队列、歌词滑动及双语偏移。360dp 宽度、130% 字体下新增 3 项测试全部通过。已检查深浅色、歌词及无封面截图，并恢复模拟器的默认密度和字体大小。
