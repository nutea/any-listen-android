# v0.1.0 · 首个公开版本

Any Listen Android 非官方客户端，主要面向使用自建 Any Listen 管理个人本地音乐文件的场景。

- 音乐库、歌单和跨歌单搜索，收藏与歌单歌曲管理。
- 后台播放、系统媒体控制、随机/循环队列和重启恢复进度。
- 封面与全屏歌词左右切换、当前歌曲定位。
- 边播放边缓存；下载时保存封面与歌词，完整缓存可离线收听。
- 本地文件多选管理、浅色/深色/跟随系统主题。
- 修复封面重复刷新、歌单往返误触与下载续传一致性问题。

## 安装

Android 8.0 及以上；当前适配 Any Listen Web Server v0.11.0-beta.1，需要手机可访问的 HTTPS 服务地址。本项目不提供音乐资源或公共服务器。

安装 `any-listen-android-0.1.0.apk`。正式版包名为 `io.github.nutea.anylisten`，与此前调试版 `.debug` 独立安装；调试版的登录信息、缓存和下载不会自动迁移。首次使用正式版需要重新连接服务端。以后正式版更新使用相同签名，可直接覆盖安装。

## 范围与反馈

主要作者自用，优先维护现有功能和本地音乐管理体验。Issues 重点处理 Bug，新功能不承诺采纳或排期。首版并未覆盖所有设备和服务端部署组合；不同厂商后台限制需在系统设置中按需允许后台播放。
