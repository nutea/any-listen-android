# Any Listen Android v0.1.4-beta.3（非官方客户端）

本版本为功能测试版，versionCode 13，兼容 Any Listen Web Server `0.11.0-beta.1`。

## 新增与优化

- 新增「沉浸封面」播放页：全幅封面渐隐至封面主色背景，适配浅色控件和歌词阅读。
- 新增「宇宙尘埃」「爆炸粒子」「水晶音波」三种圆形封面动效，由解码音频的实际强度驱动。
- 播放页封面标签右上角调色盘可切换五种风格，选择自动保存；默认保留经典风格。
- 暂停、缓冲、切到歌词、进入后台或关闭系统动画时停止音波动画和强度订阅。
- 封面缺失或加载失败时显示渐变背景与占位图，不影响播放操作。

音波是音量强度驱动的装饰动画，不是 FFT 频谱或精确节拍识别；不申请录音权限，也不保存音频采样。暂时无可用采样时使用环境动效。

## 更新与验证

沿用现有 CI 签名密钥，支持从 beta.2 覆盖安装。保留既有曲库、下载与设置。

本次进行了规范及需求两路代码检视，修复损坏封面的占位显示问题，并进行单元测试、Debug/Release Lint、Android 16 ARM64 模拟器回归与本地音频实际解码测试。模拟器结果不等同于实体手机验证。
