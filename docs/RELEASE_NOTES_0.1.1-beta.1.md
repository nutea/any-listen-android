# v0.1.1-beta.1 · 网络重连修复

Any Listen Android 非官方客户端的测试版本，主要修复切换网络后播放卡住、一直加载或提示「音频不可用」的问题。

- 修复 Wi‑Fi 与移动数据切换、飞行模式开关、Wi‑Fi 接入点漫游后 IPC 会话与播放器无法自动恢复的问题。
- 网络恢复后重建会话、失效过期音频地址，并在缓冲卡住或播放出错时重新准备时间线，无需重启应用。
- 解析失败按可恢复的 IO 错误处理，避免一律显示「音频不可用」。
- 稳定网络下的正常缓冲不会被误触发重连。

## 安装

Android 8.0 及以上；当前适配 Any Listen Web Server v0.11.0-beta.1，需要手机可访问的 HTTPS 服务地址。本项目不提供音乐资源或公共服务器。

本版本为 **测试版**。正式包名仍为 `io.github.nutea.anylisten`，与调试版 `.debug` 独立安装；调试版的登录信息、缓存和下载不会自动迁移。已安装 v0.1.0 的用户应使用**同一上传密钥**签名的 APK 覆盖安装。不要重新生成签名密钥，否则无法覆盖更新。

本仓库发布环境没有 `keystore.properties`，因此本次 GitHub Release **未附带签名 APK**。签名产物需在本地保留既有上传密钥后执行 `./gradlew assembleRelease`，预期文件名为 `any-listen-android-0.1.1-beta.1.apk`。

## 如何验证重连修复

1. 登录后播放一首**未完整缓存**的歌曲，确认进度在前进。
2. 切换 Wi‑Fi ↔ 移动数据、开关飞行模式，或在不同 Wi‑Fi 接入点间漫游。
3. 预期：短暂缓冲后从当前位置继续播放，无需结束进程或重装应用。出错后点播放也应能恢复。
4. 在音乐库页（未播放）恢复网络后，下拉刷新应能工作。
5. 对照：网络稳定时，正常缓冲不应在数秒后自行重开。
