# 安装、连接与排错

面向私人 Any Listen **v0.11.0-beta.1**。分发物是签名 APK，不是应用商店包。

## 安装

1. 从私有渠道取得 APK 与 SHA-256。
2. 在手机上允许未知来源（仅本次）。
3. 覆盖安装可保留下载与会话；卸载会删除应用私有目录中的音频。

调试包 `applicationId` 带 `.debug`，与正式包可并存，数据不共享。

## 连接

1. 输入完整 HTTPS 地址，包含反代前缀（若有）。
2. 先点「测试 Hello」。成功表示 `/api/ipc/hello` 可达且常量匹配。
3. 输入密码连接。证书错误不会被跳过。
4. 错误密码会明确失败；同一 IP 失败过多会被服务端暂时封禁。

登录状态保存在本机加密存储中。进程被杀后仍保持登录；token 失效时用已存密码静默重登。手动退出或服务器密码已变更才会回到连接页。凭据不写入备份或日志。

## 界面

底部三个入口：音乐库、下载、设置。正在播放时其它页底部还有迷你播放器。

**音乐库**：服务端列表（默认 / 我喜欢 / 最近播放 / 用户歌单）、列表内搜索、播放全部、下载全部。可收藏、加入其它可变歌单；用户歌单可移除曲目。最近播放列表不可在线改。离线时不能改服务端歌单。大批量下载前会确认数量。

**正在播放**：封面、进度、上一首 / 下一首、收藏、播放模式、队列、歌词。播放模式一个按钮循环：列表循环 → 列表随机 → 顺序播放 → 单曲循环。有 LRC 时随进度高亮。没有封面或歌词不阻断播放。

**系统媒体卡片**：依赖 Media3 会话；Android 13+ 需允许通知。卡片只画歌名、歌手、封面和控件（含收藏、播放模式），不展示歌词。

**下载**：任务状态、已完成项可直接播放、失败可重试、占用与可用空间。删除只影响手机副本。半成品不会标为可离线。断网后只能播已完成项。

**设置**：当前服务器名称 / 版本 / 地址、客户端版本、仅 Wi-Fi 下载、清理播放缓存、导出诊断、退出。更换服务器前先确认是否还要保留旧副本。

## 常见错误

| 提示 | 处理 |
|---|---|
| Certificate validation failed / 证书校验失败 | 检查证书链与系统时间，不要关 TLS |
| Authentication failed / 认证失败 | 核对密码；密码变更后需重新登录 |
| Blocked IP / 失败次数过多 | 等待后再试，避免反复打错 |
| Server edits are disabled offline / 离线时不能改服务器歌单 | 离线只能播本机内容 |
| Not enough disk space / 磁盘空间不足 | 删除本机下载或清理其它应用 |
| Length mismatch / integrity | 重试整文件下载，不要手工拼接 |

导出诊断时不要分享 token、Cookie 或完整媒体 URL。

## 升级

`versionCode` 只增不减。正常升级不应要求清空数据。回退版本不承诺数据库向下兼容。
