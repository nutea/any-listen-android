# 安装、连接与排错

面向私人 Any Listen **v0.11.0-beta.1**。分发物是签名 APK，不是应用商店包。

## 安装

1. 从私有渠道取得 APK 与 SHA-256。
2. 在手机上允许未知来源（仅本次）。
3. 覆盖安装可保留下载与会话；卸载会删除应用私有目录中的音频。

调试包 `applicationId` 带 `.debug`，与正式包可并存，数据不共享。

## 连接

1. 输入完整 HTTPS 地址，包含反代前缀（若有）。
2. 可先点「测试连接」，确认服务器可达；也可以直接输入密码连接。
3. 输入密码连接。证书错误不会被跳过。
4. 错误密码会明确失败；同一 IP 失败过多会被服务端暂时封禁。

登录状态保存在本机加密存储中。进程被杀后仍保持登录；token 失效时用已存密码静默重登。手动退出或服务器密码已变更才会回到连接页。凭据不写入备份或日志。

## 界面

底部三个入口：音乐库、本地、设置。正在播放时其它页底部还有迷你播放器。

**音乐库**：总览顶部横排「我喜欢 / 最近播放 / 默认列表」三个大图标入口，下方以封面、名称、歌曲数展示自定义歌单。点击入口进入歌曲清单，保留排序、批量操作、播放全部与下载全部。歌曲行显示封面、歌名、歌手；不展示喜欢和下载/缓存状态。当前歌曲用动态音量条标识，暂停时静止，系统关闭动画时也静止。点当前曲或迷你播放器进入全屏；返回后保留列表位置。「更多」菜单可收藏、加入歌单、下载、移除（移除前确认）。离线时不能改服务端歌单。联网时自动接收服务端的歌单变化，更新名称、歌曲与顺序；短时间内的连续变化会合并同步，断线重连后自动补齐，无需手动刷新。回到前台时按时间间隔补查，持续连接时每 5 分钟兜底校对；无需反复进出页面。

**搜索**：从总览或歌单右上角进入独立页面。按歌名、歌手、专辑搜索全部已同步歌单，支持空格分隔的组合关键词；同一歌曲合并展示并标注所属歌单，不同版本的同名歌曲分别保留。点击结果从该曲开始播放搜索结果清单。搜索不会筛掉原歌单中的歌曲，返回后仍可浏览完整歌单。离线可搜索已同步内容，播放需要本机有完整缓存或下载。

**正在播放**：封面与歌词是并列视图，进度和主控固定在下方。收藏、下载、加入歌单在同一排。播放模式与队列仍从主控进入；队列入口不显示数量角标。歌词可点击定位；手动浏览后点「回到当前句」恢复跟随。没有时间戳的歌词不能跳转。封面会给播放页一层低饱和背景。

封面页用歌手信息旁的离线图标表示歌曲可离线播放。下载入口显示下载箭头或已下载对勾；已下载且本地文件存在时禁用点击，完整播放缓存仍可下载。歌单和搜索菜单使用相同规则。

**自动缓存歌曲**：位于设置的存储分组，默认开启。关闭后停止完整音频的后台自动缓存，封面和歌词继续默认缓存；已有缓存与已下载文件保留，手动下载不受影响。再次开启后，当前播放歌曲可恢复自动缓存。开关跨重启保存。播放器必要的内存缓冲不受影响，关闭后新建播放数据源只读取已有磁盘缓存。

**迷你播放器**：音乐库、下载、设置共用；显示进度、播放/下一首和队列入口。队列在当前页面直接弹出，关闭后仍停留在原页面，不跳转到播放页。

**系统媒体卡片**：依赖 Media3 会话；Android 13+ 需允许通知。卡片只画歌名、歌手、封面和控件（含收藏、播放模式），不展示歌词。

**本地**：分为「已下载」「已缓存」「任务」。已下载与缓存使用和歌单一致的紧凑歌曲清单，点击整行播放，列表不显示下载或缓存状态，当前播放曲用动态音量条标识。文件大小、封面和歌词完整性以及删除入口在「更多」菜单中；删除前会确认，只影响手机副本。任务行保留状态、进度、重试与取消；失败、暂停和已取消任务右侧可直接移除，并清理半成品文件。顶部用独立存储卡片显示下载占用、播放缓存和设备剩余空间。半成品不可离线播放。下载不限制网络类型，Wi-Fi 与移动网络均可使用；旧版本的仅 Wi-Fi 偏好不再生效。

**设置**：当前服务器名称 / 版本 / 地址、客户端版本、自动缓存歌曲、清理播放缓存、导出诊断、退出。更换服务器前先确认是否还要保留旧副本。

## 常见错误

| 提示 | 处理 |
|---|---|
| Certificate validation failed / 证书校验失败 | 检查证书链与系统时间，不要关 TLS |
| Authentication failed / 认证失败 | 核对密码；密码变更后需重新登录 |
| Blocked IP / 失败次数过多 | 等待后再试，避免反复打错 |
| Server edits are disabled offline / 离线时不能改服务器歌单 | 离线只能播本机内容 |
| Not enough disk space / 磁盘空间不足 | 删除本机下载或清理其它应用 |
| Length mismatch / integrity | 重试整文件下载，不要手工拼接 |

导出诊断时不要分享 token、Cookie 或完整媒体 URL。

## 升级

`versionCode` 只增不减。正常升级（同一上传密钥）不应要求清空数据。更换上传密钥后无法覆盖安装，必须卸载再装，应用私有下载与登录状态会丢失。回退版本不承诺数据库向下兼容。


## 离线音频、歌词与封面

播放时边读取边缓存音频，并保存歌词和封面，不会另外启动一次整曲下载来争抢带宽。缓冲足够开始播放后即可收听，完整连续读取后才保存为完整离线音频；中途切歌或跳过未读取部分时，不将残缺数据标为可离线播放。播放页出现离线可用图标后，即使断网重启也可播放；缓存尚未完成时不能保证整首离线可用。未在新版中播放过的歌曲，需要先在线播放或下载。

下载歌曲会一并保存服务端可提供的封面和歌词。若附带资源请求失败，音频仍然保留，下载页会提示再次下载补齐；再次下载已完成歌曲不会重复下载音频。

“清理播放缓存”会删除自动缓存的音频，不删除明确下载的歌曲、已保存歌词或本地封面。卸载或清除应用数据会删除这些本地资源。

本地页三个标签均可点右上角「多选」或长按歌曲/任务进入选择模式，支持全选、取消全选和返回退出；切换标签会清空选择。已下载与已缓存支持批量播放、稍后播放、删除本机副本；任务支持批量重试、取消和移除，仅处理所选项中状态适用的任务，删除、取消及移除前会显示数量并确认。

设置页「主题」支持浅色、深色、跟随系统，默认跟随系统。切换立即应用到全应用（包括播放页及系统栏），重启保留选择。


### 缓存更新

离线时直接使用已保存的完整音频、封面与歌词。联网后，在恢复连接及定期检查时安排已有缓存更新；正常检查间隔为 15 分钟，点击音乐库「刷新」可请求立即检查。缓存维护在空闲时执行，开始播放或缓冲会暂停维护，回到空闲后继续；音乐库刷新指示不再等待整个缓存检查完成。不会为了更新缓存下载整个远端音乐库。

封面与音频优先使用 ETag / Last-Modified 条件请求；服务端未提供版本标记时重新获取并比较内容，所以同一地址的文件替换也能更新。歌词会重新请求并比较文本。只有完整响应通过验证后才原子替换旧文件，网络错误、超时或无效响应保留原副本。封面和当前歌词更新后会刷新显示；正在打开的音频继续播放，新副本供之后播放使用。

关闭「自动缓存歌曲」会停止新歌曲的自动保存，已有缓存与明确下载的歌曲仍可检查更新。上游服务若自身仍返回旧内容，客户端只能以服务端实际返回的内容为准。

播放页和底部迷你播放器在等待音频时显示进度环与“加载中…”，此时仍可点暂停取消自动继续播放。用户手动暂停、播放恢复或发生错误后，加载提示消失。

歌曲清单固定工具栏的“定位当前播放”按钮可滚动到当前歌曲并短暂高亮；若当前歌曲不在这份清单中，按钮置灰。列表缺少封面地址时会按需查询服务端封面，无需先播放歌曲；服务端未提供封面的歌曲仍使用占位图。
