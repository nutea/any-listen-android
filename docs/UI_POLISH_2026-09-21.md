# 新增功能界面优化 · 2026-09-21

范围：歌曲评论、歌词设置（翻译、罗马音、逐字高亮、偏移）、歌单管理。

## 参考与取舍

参考 QQ 音乐开发者发布的 [Google Play 页面与官方截图](https://play.google.com/store/apps/details?id=com.tencent.qqmusic&hl=zh-CN) 中的内容分区、头像与正文对齐、轻量辅助文字。该商店页面版本更新时间为 2023 年，不作为最新国内版界面的精确复刻依据。另查阅 [QQ 音乐 App Store 功能说明](https://apps.apple.com/cn/app/qq音乐-听我想听/id414603431)，了解歌词设置与播放器自定义的功能组织。

本项目保留蓝紫主题，以明确的文字层级、舒适的阅读间距和一致的弹层形状建立自己的样式。

## 变更

- 评论：精简头部，刷新与关闭改为图标操作；热门／最新采用文字标签与短下划线；音源为可展开胶囊；隐藏扩展技术标识。
- 评论正文：36 dp 圆形头像及缺图首字占位；昵称、日期、地区降低视觉权重；点赞计数移至右侧；正文使用 14 sp / 23 sp 行高；回复采用圆角浅色引用区；图片圆角裁切。
- 评论状态：加载、失败、空列表、无音源与未匹配歌曲居中显示；有内容时才显示固定分页栏；翻页重置滚动位置。
- 歌词：罗马音降低为辅助层级；设置按显示选项与歌词同步分组，开关整行可点；时间微调按钮等宽、范围限制及重置行为保留。
- 歌单：更多操作改为包含封面和歌单信息的底部面板；删除单独分组；新建／重命名输入增加字数计数和明确主按钮。
- 新弹层使用随浅色／深色主题变化的容器色。

## 验证

Debug 构建通过。评论、歌单、双语／罗马音／逐字歌词及截图交互共 10 项模拟器测试通过。截图保存在 `captures/private/ui-polish-20260921/ui-review/`。大字体使用模拟器系统字体设置进行额外验证，而非仅修改父组件的 Compose Density；弹窗拥有独立的窗口配置。

额外在 360 dp 屏宽、系统字体 130% 下运行 2 项截图与操作测试，全部通过；已目视检查评论正文、回复、分页与歌词同步控制，未出现控件重叠。测试后模拟器恢复为原来的 1080×2400 / 420 dpi、100% 字体。此次不改服务端协议或数据。
