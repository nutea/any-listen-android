## Standards

明确规范违规 0 项；非阻塞设计判断 1 项 P3。

- 唯一播放器仍由 PlaybackService 持有，符合 ARCHITECTURE.md「PlaybackService 持有唯一 Player 和 MediaSession；Activity 不管理播放器生死」。小组件复用此播放器，均衡器绑定实际音频会话。
- 歌单排序、移动、追加均限制在线及可编辑列表，并读取确认；本地快照仅在刷新成功后更新，符合「只联网写入歌单。写入后回读确认，失败不伪报成功」。
- Room 使用增量迁移；播放结束持久化改用独立有序协程，不阻塞主线程。
- 新增依赖记录确切版本、上游来源、完整许可证及运行时清单。测试说明区分协议夹具、模拟器与未验证真机场景；未发现凭据进入变更。
- 可能的 Primitive Obsession：AppViewModels.kt 的 applyLyrics／resetLyrics 和 LyricRepairSheet.kt 回调使用 server: Boolean 区分本机与服务器作用域，可后续改为 LyricScope.LOCAL／SERVER。当前按钮与映射明确，未发现写错作用域，不阻止发布。
