# v0.1.2 · 网络重连与会话稳定性

Any Listen Android 非官方客户端的正式版本。相对 GitHub 此前 Latest 的 **v0.1.0**，本版纳入 0.1.1 各测试版已验证的修复：网络切换后播放恢复、CI 标签签名，以及连接 / 会话重构。用户已确认 **0.1.1-beta.5** 在播放未缓存歌曲时切换网络不再崩溃。

相对 v0.1.0：

- **网络重连（PR #1 一脉）。** Wi‑Fi ↔ 移动数据、飞行模式、接入点漫游后重建 IPC 会话与播放，避免卡住加载或提示「音频不可用」。稳定网络下的正常缓冲不会误触发重连。
- **CI 标签签名（PR #4 / beta.2）。** 推送版本标签后由 GitHub Actions 解码仓库 Secrets、签名 Release APK 并挂到 GitHub Release。上传密钥别名为 `upload`；v0.1.0 使用的旧密钥已弃用。
- **连接 / 会话重构（PR #7 / beta.5）。** 单一 `SessionConnectionManager` 与 `ConnectionPlanner`，稳定网络身份，IPC 完成幂等；API 与音频使用独立 OkHttp dispatcher。健康会话不会因系统第一次网络回调而误拆；网络身份真正变化时才重建；同一链路抖动则先探活。
- **beta.3 的 SecureSessionStore hardening 已撤回。** 那套 EncryptedSharedPreferences wipe / fallback 未能解释「连上服务器后崩溃」，在 beta.4 已回退，本正式版也不包含。
- **登录闪退与播放中切网闪退均已修复。** 登录或会话恢复成功后进程保持存活；播放未缓存歌曲时切换 Wi‑Fi / 移动数据不再杀死进程。

版本号 0.1.2（versionCode 9）。版本名不含 beta / rc / alpha，打标签 `v0.1.2` 后现有 CI 会发布正式 Release（非 Pre-release）。未轮换签名密钥。

## 安装

Android 8.0 及以上；当前适配 Any Listen Web Server v0.11.0-beta.1，需要手机可访问的 HTTPS 服务地址。本项目不提供音乐资源或公共服务器。

本版本为 **正式版**。正式包名仍为 `io.github.nutea.anylisten`，与调试版 `.debug` 独立安装。可覆盖安装 v0.1.1-beta.2 及之后的测试版（同一上传密钥）。从 v0.1.0 或任何旧签名 / 未签名安装包升级须先卸载；卸载会删除应用私有下载与登录状态。

## 如何验证

1. 全新安装或清除应用数据后打开客户端，应能进入连接页。
2. 填写自建 Any Listen Web Server 地址并登录。预期：连接成功后进入曲库，进程保持存活，不会在登录成功后立刻闪退。
3. 杀进程再开：应自动恢复会话并停留在曲库。
4. 播放一首**未完整缓存**的歌曲，确认进度在前进；然后在 Wi‑Fi 与移动数据之间来回切换。预期：进程保持存活，短暂缓冲后从当前位置继续播放。
5. 对照：网络稳定时，正常缓冲不应自行重连。

## 范围与反馈

主要作者自用，优先维护现有功能和本地音乐管理体验。Issues 重点处理 Bug，新功能不承诺采纳或排期。首版之后的稳定性修复并未覆盖所有设备和服务端部署组合；不同厂商后台限制需在系统设置中按需允许后台播放。
