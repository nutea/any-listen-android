# 圆形封面音波动效

参考用户提供的三张截图，新增宇宙尘埃、爆炸粒子、水晶音波三种风格，沿用播放页右上角调色盘与 DataStore 偏好保存。原有经典和沉浸封面保留。

## 实现

- Compose Canvas 绘制星尘、环形粒子、双层折线与三角碎片，圆形封面使用独立旋转层；动态数据仅在绘制阶段读取，不逐帧重组整个播放页。
- Media3 TeeAudioProcessor 只读观察解码 PCM，每个缓冲区最多采样 512 个值，采样步长避免只读取立体声的静音声道。数据原样送往音频输出，不申请录音权限，不保存音频采样。
- 使用 RMS 与峰值控制波纹幅度、扩散范围与透明度；角度分布和漂浮轨迹为程序化装饰，不宣称 FFT 频谱或精确节拍识别。
- 帧更新上限约 30 fps。只在可见、RESUMED、正在播放且未缓冲时订阅强度；切到歌词、暂停、后台或关闭系统动画后停止。没有新采样时 500 ms 后回落到环境动效。
- 取色和封面缓存复用上一项播放页风格实现。用户截图未纳入应用资源。

## 验证

- Debug / AndroidTest 构建及 Debug Lint 通过。
- 两项音频采样单测通过：静音/有声/浮点边界、关闭采样、输入位置不变，以及经 Tee 处理后的 PCM 与原输入逐字节一致。
- 播放器模块完整 14 项单测全部通过，无跳过。首次运行受 Robolectric 依赖下载的 TLS 错误影响；从 Maven Central 下载并校验 SHA-512 后，以本地依赖重新运行通过，未修改项目仓库配置。
- 设备回归 8 项通过（另有默认跳过的录屏用例）：三种效果均会变化且暂停后画面冻结，菜单切换、歌词页禁用采样、前后台生命周期、偏好保存、原有沉浸风格和无封面场景正常。
- 使用本地合成 WAV 经真实 ExoPlayer 解码，验证实时强度采样；无服务器写入。
- 360dp / 130% 字体 / 系统动画关闭组合下，两项菜单和动画开关回归通过；测试后恢复默认密度、字体和系统动画。
- 另运行录屏用例，生成三种效果连续预览。暂停截图比较先等待 RenderThread 完成最后一帧，避免把已提交的渲染帧误判为动画仍在运行。
