# 完整开发计划

基线日期：2026-09-13。计划状态：待执行。全部任务默认未完成；工期为单名熟悉安卓音频开发者的估算，不是交付承诺。

## 1. 产品目标与边界

目标闭环：服务器管理自有音乐 → 安卓读取歌单 → 原生后台播放 → 单曲/歌单下载 → 断网冷启动后浏览并播放下载内容 → 联网刷新库。

首版必须：HTTPS 登录、会话恢复、歌单浏览、列表内搜索、播放队列、随机/循环/跳转、通知栏与锁屏控制、耳机控制、音频焦点、下载状态管理、离线库、联网收藏/歌单增删曲目、清晰的错误提示。

首版基础展示：歌名、歌手、专辑、封面；有可用接口时显示基础 LRC 歌词。封面歌词缺失不阻断音频播放。

明确不做：多账号/多服务切换、离线修改服务端歌单、播放进度跨设备接力、服务器文件删除或标签编辑、在线音源市场、DRM 绕过、逐字歌词编辑、音效引擎、Android Auto/车机适配、投屏、应用商店发布。

发布形态：私人仓库交付签名 APK，安装到用户设备。Android Auto、全局搜索及复杂专辑视图作为后续范围。

## 2. 已知与待确认

已知：服务端版本 v0.11.0-beta.1，公网 HTTPS；官方项目有本地/WebDAV 音乐和 WebDAV 列表同步。前期源码检查说明存在 HTTP/WebSocket 交互，但未证明是稳定第三方 API。

待确认：实际部署摘要与对应源码、认证协议、歌曲 ID 稳定性、音频鉴权/Range、歌单写入语义、反代前缀/超时、目标安卓机型和系统、库规模、典型格式、可接受磁盘占用、发布签名归属。

实现前提：开发期间服务端固定版本。先复用现有协议，通过适配层隔离；只有验证证明缺口后才提出最小服务端补丁。新 API 的路径和字段必须由验证结果决定，不虚构现成接口。

## 3. 里程碑及依赖

主依赖：M0 → M1 → M2 → M3 → M4 → M5。M4 的只读同步可在 M2 完成后穿插，但首版发布必须通过 M3 离线门槛。

| 阶段 | 估算 | 工作和交付 | 退出标准 |
|---|---|---|---|
| M0 协议验证 | 3–5 人日 | 版本定位、脱敏接口文档、请求脚本和响应样本、歌曲身份结论 | 登录、真实歌单、音频播放/Range 有证据；所有缺口有处理决策 |
| M1 项目基础 | 4–6 人日 | Gradle 工程、Compose 导航、适配层、Room、登录、CI | 空环境可构建；错误密码/会话恢复/离线入口可测 |
| M2 在线播放 | 7–10 人日 | 库与列表、媒体服务、队列/模式、系统控制、错误恢复 | 真机锁屏 30 分钟连续切歌；拖动、耳机和来电中断通过 |
| M3 离线闭环 | 8–12 人日 | 持久下载、恢复、完整性校验、离线索引、容量管理 | 飞行模式冷启动可播；中断、过期 URL、磁盘不足、删除副本通过 |
| M4 歌单与体验 | 5–8 人日 | 在线收藏/曲目增删、刷新、封面、基础歌词、无障碍 | Web 与安卓结果一致；写入失败不伪报成功 |
| M5 稳定与发布 | 7–10 人日 | 真机矩阵、性能、升级测试、签名 APK、使用/排错文档 | 阻断问题清零，测试证据齐全，可安装升级并保留下载 |

合计约 34–51 人日，预留 20% 不确定性后约 8–12 周。若需新增服务端认证/媒体接口、歌曲标识迁移或额外机型适配，在 M0 后重新估算。可先发布 M2 联网原型，不能将其称为完整首版。

## 5. 页面与交互

- 连接页：HTTPS 地址、凭据输入、连接测试、错误原因。不能通过跳过证书校验来“修复”连接。
- 音乐库：服务端列表、本地缓存、手动刷新；明确最近刷新时间和离线状态。
- 列表详情：歌曲、列表内搜索、播放全部、下载全部；大歌单下载前展示数量和已知大小。
- 播放页：封面/基础歌词、进度、队列、播放模式；底部常驻迷你播放器。
- 下载页：任务状态、已下载、失败重试、仅 Wi-Fi、占用；删除不影响服务器原文件。
- 设置：服务器信息、缓存/下载管理、诊断导出、版本、退出；更换服务需明确处理原副本。

## 6. 风险及决策门槛

测试版协议变化：适配层+脱敏固定样本+服务器版本兼容表；首版只承诺指定版本。
歌曲 ID 随路径变化：先保留旧条目为孤立下载，不按歌名模糊合并；稳定映射作为补丁候选。
不支持 Range：在线播放兼容性单测；下载可退回完整重试，不虚假续传。
无并发保护的歌单写入：只开放已证实安全的操作；无法实现时必须记录首版范围变更，不能悄悄忽略。
后台受系统限制：按官方媒体服务实现，并测试用户机型；不依赖无限后台轮询。
音乐格式差异：按样本验证，不宣称所有无损格式均支持，不默认增加服务端转码。

## 7. 工作规范与完成定义

每项任务提交实现、相关测试、验证结果和已知限制。未执行真机测试标记未验证。计划先行不等于功能完成。
M0 之前可做无凭据工程工作；实际接口验证等待域名和受保护的测试凭据。不得把凭据写入仓库或 Issue。
不批量复制上游代码。复用前检查对应版本许可证并记录来源；发布前确定本仓库许可和第三方声明。
部署服务端补丁、升级生产版本、破坏性音乐操作必须单独明确范围；本计划不授权自动更改生产服务。
