# Any Listen Android v0.1.4-beta.2（非官方客户端）

本版本为功能测试版，versionCode 12，兼容 Any Listen Web Server `0.11.0-beta.1`。

## 新增与优化

- 歌单管理：新建、重命名、删除和调整顺序，保护内置及音源歌单。
- 歌词：双语、罗马音、逐字高亮，以及每首歌曲独立的歌词偏移；下载时保存可用的多种歌词供离线使用。
- 歌曲评论：切换评论来源、热门/最新评论、分页及回复展示，提供加载失败重试。
- 歌手与专辑页面：从曲库及播放器进入，支持搜索、专辑曲序与播放。索引来自当前曲库，并非音源的完整歌手作品库。
- 精细调整评论、歌词设置及歌单管理界面，适配深浅色、小屏和大字体。
- 包含暂停状态切歌恢复播放、播放时重新校验服务端歌词的修复。

beta.1 在 CI 检查中发现异步测试时序问题，未发布安装包。本版修复测试同步，保留既有标签不改写。

## 更新说明

沿用现有 CI 签名密钥，从 v0.1.3 可覆盖安装；数据库升级保留曲库与下载记录。评论依赖服务端扩展支持及网络，当前仅支持阅读。逐字歌词与罗马音需要音源提供对应数据。

本次验证包含单元测试、Debug/Release Lint、Android 16 ARM64 模拟器回归；此前已使用真实服务器验证播放、歌词、歌单、评论与歌手/专辑入口。模拟器结果不等同于实体手机验证。
