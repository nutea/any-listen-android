# 第三方与来源

本客户端 **没有** 批量复制 Any Listen 源码。HTTP/IPC 路径与字段来自公开仓库
[any-listen/any-listen](https://github.com/any-listen/any-listen) 标签 `webserver-v0.11.0-beta.1`
（提交 `e4ef53a5094473687e2d142fb7b63a530436b982`）的阅读结果。

message2call 帧格式依据 [lyswhut/message2call](https://github.com/lyswhut/message2call)（MIT）在本仓库重实现 REQUEST/RESPONSE。

Android 依赖见 `gradle/libs.versions.toml`：AndroidX、Media3、OkHttp、Coil、Kotlin 等各自许可证。
发布前由仓库所有者确定本仓库 SPDX 许可，并附完整第三方声明。
