# M0：接口验证与 Hermes 执行清单

本文件是待填写的验证合同，不是现有 API 文档。目标仅为已部署的 v0.11.0-beta.1。

## 输入

需要域名/可选路径前缀、受保护的凭据、镜像摘要、对应上游源码、可用的非破坏性测试歌单和少量授权音乐。不要索取或提交整个生产数据目录。可先检查公开源码、准备脚本；缺少连接信息时明确等待项。

## 方法

定位该版本的登录/HTTP/IPC WebSocket/媒体代理代码，结合用户授权的浏览器网络记录或只读请求验证。不凭 main 分支推断测试版全部接口。
真实请求数据只保存在忽略目录，提交手工审查后的脱敏 fixture；去除凭据、私人曲名、域名、路径和带签名 URL。

## 能力表（全部待验证）

| 能力 | 必填证据 |
|---|---|
| 登录 | 方法/路径或消息、body、成功/失败响应、Cookie或令牌、期限、退出 |
| 认证恢复 | 重启恢复方式、失效响应、刷新是否存在、并发刷新规则 |
| WebSocket | 握手认证、URL前缀、消息关联ID、心跳、重连、事件顺序 |
| 列表与曲目 | 分页或全量、schema、空值、稳定ID、重复曲目、版本号 |
| 音频解析 | URL生命周期、认证头、重定向、MIME、Content-Length |
| Range | bytes=0-1023 的实际206与Content-Range；非零偏移、416行为 |
| 封面/歌词 | 鉴权、缓存、缺失响应、歌词格式、是否需要扩展 |
| 收藏/歌单 | 操作语义、响应、幂等性、并发控制、写后读取 |
| 文件变更 | 测试副本移动/替换后的ID变化；不改生产原曲 |
| 反向代理 | HTTP/WSS均可用、超时、路径前缀、是否额外登录层 |

逐项填写：状态（通过/失败/未验证）、日期、源码提交/文件、脱敏请求响应、复现步骤、影响及处理。

## 输出文件

- docs/api/COMPATIBILITY.md：版本、镜像摘要、能力状态。
- docs/api/PROTOCOL.md：验证后的实际接口与错误语义。
- docs/adr/001-server-integration.md：直接复用/补丁决策与替代方案。
- tools/probe/：通过环境变量或交互输入秘密的验证工具，不默认执行写操作。
- tests/fixtures/：脱敏且可重用的协议样本。

## 门槛与缺口处理

M0 必须证明可认证获取歌单与授权音频；不能只验证首页200。
Range 不支持需明确降级，不阻止普通完整下载，但不得宣称断点下载通过。
若服务端缺少稳定ID/安全写接口，给出最小改动设计、兼容与回滚影响，交用户确定再修改生产；默认保持生产不变。
测试歌单写操作只能针对明确指定的独立测试歌单。所有远端变更记录前后状态，禁止删除音乐文件。
