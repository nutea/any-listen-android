# Any Listen Android v0.1.4-beta.4（非官方客户端）

本版本为功能测试版，versionCode 14，兼容 Any Listen Web Server `0.11.0-beta.1`。

## 播放工具

- 定时停止：15／30／60 分钟、自定义分钟数、当前歌曲结束后停止；支持倒计时和取消。
- 队列拖动排序：分别调整待播与稍后播放顺序，保留当前歌曲和进度，保存随机播放顺序。
- 音频信息：展示播放器实际取得的格式、码率、采样率、声道及音频来源，缺失字段不推测。
- Android 桌面小组件：封面、歌名、播放／暂停、前后切歌、收藏及返回播放页。
- 均衡器：预设、自定义频段和一键还原；使用当前播放器的音频会话，频段与可用性由设备决定。
- 保音高倍速：0.5× 至 2×，设置保存在本机，重启后恢复。

## 歌词与曲库

- 歌词修复：通过服务器扩展检索候选并预览，也可导入带时间轴的 LRC；支持 UTF-8／GB18030，文件不超过 1 MiB。
- 明确歌词作用范围：「仅应用到本机」保留独立覆盖；「保存到服务器」使其他客户端也能使用。支持清除本机覆盖或服务端编辑，保留翻译、罗马音和逐字歌词信息。
- 普通歌单曲目管理：保存拖动后的曲目顺序、批量移至其他歌单、复制歌单、提示重复曲目；只开放可编辑歌单，写入后读取确认。
- 搜索历史、拼音／首字母搜索及仅已下载筛选；新增常听、久未听与随机探索入口。
- 本机听歌统计：从本版本开始记录实际可听时长和播放次数，不从旧最近播放列表补造数据。

歌词候选依赖服务器已安装并声明的扩展。搜索和智能曲库仍以已同步歌曲为范围；手机播放队列、音效和统计独立于 Web 播放状态。

## 更新与验证

沿用现有 CI 签名密钥，支持从 beta.3 覆盖安装。数据库采用增量迁移，保留曲库、下载及设置。

发布前完成规范及需求代码检视、单元测试、Debug／Release Lint、Android 16 ARM64 模拟器回归与本地 WAV 实际播放测试，并检查 360dp 小屏、130% 字体和深色界面。详细结果见 [测试记录](TEST_EVIDENCE.md) 和 [审查记录](REVIEW_0.1.4-beta.4.md)。本轮服务端写入使用协议夹具验证，未修改真实服务器歌单或歌词，未进行实体手机验收。
